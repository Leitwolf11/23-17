# Security policy

Use GitHub's private vulnerability form to report suspected vulnerabilities to the project maintainers. [Report a vulnerability](https://github.com/Leitwolf11/23-17/security/advisories/new)

Include the affected version or full commit ID, your operating system, the affected game feature or release artifact, and the impact you observed. Share only the information the maintainer needs to assess the report. Remove credentials and personal data from any logs you include.

Maintainers will assess the report, coordinate a fix where applicable and agree on disclosure timing with the reporter. Please keep the details private while the fix is being prepared.

Use the issue tracker for ordinary gameplay, performance and localization bugs.
