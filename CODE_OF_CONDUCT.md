# Code of conduct

Everyone should be able to play, discuss and contribute to 23.17 without harassment. Treat other people with respect, give feedback on the work and make room for contributors with different backgrounds and levels of experience.

Harassment, threats, discriminatory remarks, unwanted sexual attention, personal attacks and sharing someone's private information without consent are unacceptable.

This policy applies to project spaces, including GitHub issues, pull requests and discussions, and to conduct while representing the project.

Report concerns privately to a project maintainer using a contact method listed on their GitHub profile. If the report concerns a maintainer, contact another maintainer where possible. For violations of GitHub's rules, you can also use the platform's reporting tools.

Maintainers will handle reports as confidentially as possible. Depending on the conduct, they may remove content, issue a warning or restrict access to project spaces.
