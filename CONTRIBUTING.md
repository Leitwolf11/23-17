# Contributing to 23.17

Read the [code of conduct](CODE_OF_CONDUCT.md) before participating. Use [private security reporting](SECURITY.md) for suspected vulnerabilities.

## Issues and pull requests

1. Search open and closed GitHub issues for your topic. Use the matching issue template to report a bug or suggest a change.
2. Fork the repository, create a branch from the current default branch and keep each pull request focused on one change. For larger changes, discuss the idea in an issue first.
3. Verify your changes and describe the checks you ran in the pull request. For performance changes, record the hardware, resolution, graphics preset and test route.
4. Push your branch to your fork and open a pull request against the project's default branch. Link any related issue.

See [Versioning](VERSIONING.md) for release identifiers.

## Licenses

Contribute project code under the [MIT License](LICENSE). Contribute game assets, including models, textures, music and sound effects, under [CC0 1.0 Universal](assets/LICENSE). For any third-party asset, include its source and verify that it is already available under CC0 1.0 Universal.

## Commit sign-off

Sign off each contribution commit under the [Developer Certificate of Origin 1.1](https://developercertificate.org/) with `git commit -s`. Git adds a `Signed-off-by` line using your name and email. The sign-off certifies your right to submit the contribution under the terms that apply to it.
